Instructions for authors

Prineeth Ramachandra

The editorial office, which is also the author's desk

Received 15 November 2026. Accepted the same day, by the same person.

This paper describes the format of the Journal of Personal Curiosities and is itself set in that format. It covers the parts of a paper, how figures and interactive figures are made, and how notes, equations and references number themselves. It ends with the steps for publishing a new paper. Authors who would rather not read it can copy the template and start typing.

format, figures, footnotes, plain HTML

Scope

The Journal publishes whatever its editor became curious about and could not leave alone. Papers combine writing with visuals. There is no word limit and no schedule.

The format borrows the furniture of an academic paper: an abstract, numbered sections, numbered figures, footnotes and a reference list. These conventions are tedious to produce and surprisingly pleasant to read around, because a reader always knows where they are and what a thing is called.Peer review has been retained in a simplified form. See the dates above. Everything else about a paper is a web page, so a figure can move, respond, or be a small program.

Anatomy of a paper

A paper is one HTML file in its own folder, linked to one shared stylesheet and one short script. shows the parts in the order they appear. lists the markup for each.

Nothing is numbered by hand. Moving a figure above another renumbers both, along with every sentence that points at them. A link to an id that does not exist is printed as “??”, as tradition requires.

Figures

A figure may hold an image, an inline SVG drawing, a video, or a few HTML elements and a script. Tufte's advice on static graphics applies unchanged : the figure should show the thing, with as little else as possible. Where the reader would learn more by changing something than by being told about it, the figure should let them .

There is no build step, and no framework to learn or to outlive.Knuth's argument for keeping a program and its explanation in one document works just as well for a paragraph and its figure.

Notes, equations and references

A footnote is written where it is called, in the middle of the sentence, and the journal carries it to the end of the paper. Notes are for asides. Anything the argument depends on belongs in the text.

Simple equations are written in plain HTML. The number of characters on a line is roughly

n ≈ wc s

where w is the width of the column, s is the font size, and c is the average width of a character as a fraction of the font size, a little under one half for most text faces. is how the column width of this journal was chosen. A paper with heavier mathematics can load a typesetting library in its own head.

References go in a list at the end. Each item has an id, and an empty link to that id becomes its number in brackets.

Publishing a paper

  1. Copy the folder papers/_template and rename it. The folder name becomes the address.
  2. Write the paper in its index.html. Put images in the same folder.
  3. Add one entry for it to the contents list on the cover page.
  4. Commit and push. The paper is published when the push finishes.
